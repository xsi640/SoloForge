# SoloForge

SoloForge 是一个以 AI 时代软件开发工作方法为核心的项目文档与实践仓库，目标是把“想法 → 产品设计 → 研发 → 测试 → 发布”这条链路整理成一套简单、可复用、适合长期坚持的开发方法。

## 项目定位

这个项目目前重点关注：

- 把开发过程整理成可复用的工作方法
- 用 AI 提升需求拆解、文档生成、任务分解和测试辅助能力
- 让每个阶段都能有明确输出，便于后续执行、调整和复用
- 在不追求复杂流程的前提下，尽量保持简单、可验证、可迭代

## 当前建议的开发方法

### 1. Idea 与目标确认
- 明确要解决的问题
- 确定目标用户和核心价值
- 设置成功标准
- 审核 AI 生成的 idea 草案

### 2. 产品设计与 UI/UX
- 明确页面结构、关键功能与交互流程
- 产出产品设计与 UI/UX 草图说明
- 确认先做什么、后做什么

### 3. 研发阶段
- 输出技术方案简版
- 产出 API 文档
- 生成任务文档，用于 AI 并发开发与任务进度跟踪
- 进行代码实现与文档补充

### 4. 测试阶段
- 制定测试重点和关键路径
- 让 AI 生成测试用例与辅助建议
- 进行人工测试与问题修复

### 5. 发布阶段
- 编译与构建产物
- 准备部署包
- 生成发布说明与回滚方案
- 发布后进行验证

## AI 的使用方式

AI 在这个项目中主要承担：

- 需求拓展与梳理
- 产品结构与交互说明的生成
- API 文档草案
- 任务拆解与并发开发任务的组织
- 测试用例生成与问题汇总
- 发布说明与回滚建议

AI 不承担最终决策，最终判断和责任仍然由人来负责。

## 设计原则

- 简单优先：不要为了流程而流程
- 可复用：每个阶段都有明确可复用输出
- 可验证：每个目标都有验收标准
- 可迭代：每次迭代都留下可追踪记录
