# 阶段 3：研发阶段

## 目标
把设计变成代码，并产生任务文档，用于支撑 AI 并发开发与任务进度可视化。

## 人的工作
- 明确技术方案与关键实现方式
- 审核 API、数据结构和任务拆解结果
- 负责核心业务逻辑、关键判断和边界处理
- 跟踪任务进度，确认状态变化
- 对 AI 生成代码进行校验和必要修正

## AI 可以协助的内容
- 生成 API 接口清单
- 生成任务文档
- 拆分并发开发任务
- 生成代码骨架
- 生成文档摘要
- 汇总任务进度与风险

## 必须产出的内容
- 技术方案简版
- API 文档
- 数据结构或模型说明
- 任务文档
- 代码实现
- 任务进度状态

## 任务文档建议结构
- 任务编号
- 任务名称
- 任务目的
- 依赖项
- 执行方式
- 当前状态
- 验收标准
- 备注与风险

## 检查清单
- 任务是否可独立执行
- 依赖是否明确
- 任务状态是否可追踪
- 关键逻辑是否已人工确认
- API 文档是否与实现一致

## 输出示例

### 任务文档
| 任务编号 | 任务名称 | 状态 | 依赖项 | 验收标准 |
|---|---|---|---|---|
| T-01 | 用户登录 | 待处理 | 无 | 能成功登录并返回用户信息 |
