# 宠物档案 App 需求分析文档

## 1. 项目概述

一个面向养宠物用户的宠物档案 App，支持管理多只宠物，围绕每只宠物提供档案、生活记录（含日记）、病例、相册、定期提醒和时间轴等功能。

- 覆盖猫、狗、爬宠等各类宠物
- 支持一个用户管理多只宠物
- 跨平台
- 采用本地记录，不依赖云端

## 2. 目标用户

- 养猫、狗、爬宠等各类宠物的个人用户
- 养多只宠物、需要分别管理档案的用户
- 希望长期记录宠物成长和健康状况的用户

## 3. 要解决的问题

- 宠物成长过程、照片、事件分散，缺少集中记录
- 多只宠物信息容易混淆
- 疫苗、驱虫、体检等定期事项容易忘记
- 就医、用药等记录分散，难以回顾
- 照片散落在手机相册，不便按宠物整理

## 4. 需求目标

### 4.1 宠物档案

为每只宠物建立独立档案，支持多宠物管理。字段包括：

- 名字
- 头像 / 照片
- 物种（猫、狗、爬宠等）
- 品种
- 性别
- 生日 / 出生日期
- 到家日期
- 当前体重
- 绝育情况
- 备注

其中「当前体重」取生活记录中最新的一条体重记录。

### 4.2 生活记录

记录宠物在日常生活中发生的、与时间相关的事件和变化，内容包括：

- 日记（可定期记录，内容包含视频、图片、文字）
- 体重变化
- 生日 / 到家日
- 绝育 / 发情
- 就医事件（可关联到对应病例）
- 自行用药
- 自定义事件

每条记录按时间保存，并关联到具体宠物。

### 4.3 病例

独立模块，用于管理完整的医疗信息：

- 就医记录
- 用药记录
- 诊断与处置信息

病例独立管理，不与其他模块混用。

### 4.4 相册

- 汇总所有模块中的图片和视频
- 支持独立上传照片和视频
- 包含视频

### 4.5 定期提醒

- 类型包括：疫苗、驱虫、体检、喂药、洗澡、剪指甲等
- 系统内置按「物种 + 提醒类型」组合的默认周期
- 默认周期可修改，用户也可自定义周期
- 到期时通过系统通知提醒
- 不做提前提醒
- 完成后可标记完成并记录实际完成日期
- 逾期后需要有明确的展示方式
- 通知权限关闭时，App 内提供「待处理提醒」列表兜底

### 4.6 时间轴

- 汇总显示所有内容：生活记录（含日记）、病例、相册、已完成的提醒
- 未完成的提醒不计入时间轴

### 4.7 通用能力

- 支持对宠物档案、生活记录、相册、病例、提醒进行编辑和删除
- 所有记录都必须关联到具体宠物

## 5. 模块边界说明

| 模块 | 职责 |
|---|---|
| 宠物档案 | 宠物的基本信息 |
| 生活记录 | 按时间发生的日常事件和变化，含日记、体重变化、就医事件等 |
| 病例 | 完整的医疗档案，独立管理 |
| 相册 | 所有图片和视频的汇总视图 |
| 提醒 | 周期性健康与日常事项 |
| 时间轴 | 所有内容的汇总视图 |

说明：

- 日记属于生活记录的一种类型，不单列模块
- 生日 / 到家日等一次性事件归入生活记录
- 生活记录中的「就医事件」可关联到对应病例，避免重复录入
- 自行用药可直接记录在生活记录中，不强制建立病例

## 6. 成功标准

- 用户能建立宠物档案
- 用户能持续记录约半年
- 用户能设置定期提醒（如驱虫）并在到期时收到通知
- 用户愿意持续使用，而不是建完档就闲置

## 7. 范围与边界

### 必做

- 多宠物档案
- 生活记录（含日记：视频 / 图片 / 文字）
- 病例
- 相册（含视频，汇总所有模块媒体）
- 定期提醒（含物种级默认周期 + 用户修改 + 逾期展示 + 待处理列表）
- 时间轴
- 编辑与删除
- 记录关联宠物
- 跨平台
- 本地记录

### 暂不做

- 账号登录与云同步
- 数据导出与备份
- 提前提醒
- 社交、社区、分享互动
- 在线问诊、自动诊断
- 宠物电商
- 宠物医院/机构对接

## 8. 约束与风险

- **本地记录**：数据仅存本机，卸载或换设备可能丢失
- **多媒体存储**：照片和视频可能占用较多本地空间
- **通知权限**：用户关闭通知时，提醒依赖 App 内「待处理提醒」列表兜底
- **默认周期准确性**：内置周期仅作建议，不能替代兽医判断
- **物种差异**：爬宠等不同宠物的提醒类型和周期差异较大
