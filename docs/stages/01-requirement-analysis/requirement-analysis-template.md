# 需求分析模板（阶段 1）

> 说明：人只需要填写最核心的信息，AI 会基于这份模板继续追问、收集和整理，最后生成需求分析文档。

## 1. 基本信息

- 项目名称：
  - 例如：SoloForge
- 简短描述：
  - 用一句话说明你想做什么
- 目标用户：
  - 说明是谁会用这个东西

## 2. 要解决的问题

- 当前问题是什么：
  - 说明现在的痛点
- 为什么这个问题值得解决：
  - 说明它为什么值得做

## 3. 需求目标

- 目标 1：
  - 写最核心的目标
- 目标 2：
  - 可选，写次重要的目标
- 目标 3：
  - 可选，写后续扩展目标

## 4. 成功标准

- 完成后，用户能做到什么：
  - 写用户最终能完成的事情
- 这个需求算是完成的判断标准：
  - 写一个可验证的标准

## 5. 范围与边界

- 必做：
  - 这次一定要做的内容
- 暂不做：
  - 先不做、后续再做的内容

## 6. 约束与风险

- 主要限制：
  - 比如时间、技术、资源、规则等
- 主要风险：
  - 比如需求变动、技术难度、依赖问题等

## 7. 未确定事项

- 还需要确认的问题：
  - 把目前还没想清楚的点写出来
