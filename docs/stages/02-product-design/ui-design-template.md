## 3. 视觉设计规范

### 设计标准

- 视觉规范基线：
  - 间距优先使用 8px 体系
  - 普通文字与背景对比度至少达到 WCAG 2.2 AA 的 4.5:1
  - 大字号文字与背景对比度至少达到 3:1
  - 非文字 UI 组件和图形与相邻颜色对比度至少达到 3:1
  - 键盘可操作元素必须有清晰的焦点状态
  - 触控操作目标建议不小于 44×44px
