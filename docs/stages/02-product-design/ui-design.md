## 2. pen.dev 提示词

### 2.1 完整提示词（一次性生成全部 UI 设计图）

> **使用方法**：把下面 `text` 代码块整段一次性粘贴给 pen.dev，它会一次产出 `UI-001` ~ `UI-018` 覆盖的全部页面和状态设计图。
> 需要单页精修或重出某一页时，改用 2.2 加第 3 节的单页提示词。

```text
【任务】
请为一个「宠物档案 App」设计完整的移动端 UI 设计图，共 14 个页面，并为每个页面输出它的正常状态和指定的异常 / 空状态。

这是一个帮助养宠用户管理多只宠物的本地记录类 App，核心功能包括：宠物档案、生活记录（日记是生活记录的一种类型）、病例、相册、定期提醒、时间轴。用户可以同时管理猫、狗、爬宠等多只宠物。

请一次性生成全部页面，所有页面共用同一套设计系统，视觉语言保持一致。每张设计图请标注「页面编号 + 页面名 + 状态名」。

【整体风格】
温暖、友好、干净、可信赖，适合养宠用户。以卡片式布局为主，留白充足，圆角柔和，视觉重心在宠物照片和内容本身，避免过度装饰。

【设计基准与布局】
- 设计基准：375 × 812 pt
- 使用 8px 间距体系：8 / 16 / 24 / 32
- 页面左右边距 16px
- 卡片内边距 16px，卡片间距 12px
- 卡片圆角 12px，按钮圆角 10px，标签胶囊圆角 16px
- 头像使用正圆形
- 媒体网格 3 列，间距 4px
- 所有可点击元素触控区域不小于 44 × 44px

【色彩】
- 主色：#F2994A（温暖橙）；主色按压：#DE8437
- 页面背景：#FFFFFF
- 次级背景 / 分区底色：#F8F6F3
- 主要文字：#1F2933
- 次要文字：#6B7280
- 分割线 / 描边：#E8E4DF
- 成功：#2E9E6B
- 警告：#E9A23B
- 错误 / 逾期：#D9534F

【字体】
- 页面标题：20px / 行高 28px / Semibold
- 分区标题：17px / 行高 24px / Semibold
- 正文：15px / 行高 22px / Regular
- 辅助文字：13px / 行高 18px / Regular

【组件】
- 主按钮：高度 48px，主色填充，白色文字，圆角 10px
- 次按钮：高度 48px，描边样式，主色文字
- 输入框：高度 48px，圆角 10px，聚焦时主色描边
- 卡片：白底，12px 圆角，轻微阴影
- 类型胶囊：用于标注内容类型「生活记录」「病例」「相册」「已完成提醒」，圆角 16px，浅色底
- 分段控件：用于列表分组切换
- 空状态：居中线性插画 + 一句说明文案 + 一个主操作按钮
- 顶部提示条：用于通知权限关闭和提醒逾期

【可用性要求】
- 普通文字与背景对比度不低于 4.5:1，大号文字不低于 3:1，非文字组件不低于 3:1
- 提供清晰的聚焦状态
- 空状态必须包含说明文字和一个明确的操作入口
- 使用真实中文文案，不要使用 Lorem Ipsum
- 图标风格统一，使用线性图标

【页面清单】
以下 14 个页面全部需要生成，请按编号输出：

PAGE-001 宠物列表
- 顶部导航栏：左侧返回，标题「我的宠物」，右侧「添加」文字按钮
- 宠物卡片列表，每张卡片包含：圆形宠物头像、名字、第二行「物种 · 品种」、第三行「性别 · 出生日期或年龄」、第四行「当前体重 · 绝育状态」、右侧进入箭头
- 状态：正常（展示 2 到 3 只宠物）；空状态（插画 +「还没有宠物，先添加一只吧」+ 主按钮「添加宠物」）

PAGE-002 全部宠物时间轴（App 默认入口）
- 顶部导航栏：标题「时间轴」，右侧宠物切换器入口，显示当前范围「全部宠物」
- 筛选区两行横向可滚动胶囊：第一行宠物筛选（「全部宠物」加各宠物头像和名字）；第二行内容类型筛选（「全部」「生活记录」「病例」「相册」「已完成提醒」）
- 时间轴列表按日期分组，分组标题例如「今天」「昨天」「9月10日」
- 每条内容显示：左侧小圆头像、宠物名字、内容类型胶囊标签、内容摘要、缩略图（如有）、时间
- 页面内不提供新增内容入口
- 状态：正常（至少 5 条跨 2 只宠物、覆盖不同内容类型的内容）；空状态（「还没有记录，去宠物档案添加第一条内容」）；筛选无结果（「没有符合条件的内容」+「清除筛选」按钮）

PAGE-003 添加宠物
- 顶部导航栏：左侧「取消」，标题「添加宠物」，右侧「保存」
- 头像上传区：居中大号圆形占位，图标和文案「添加照片」
- 分区「基本信息」，每项带必填标记：名字（单行输入）、物种（选择器，示例选项 猫 / 狗 / 爬宠 / 其他）、品种（单行输入）、性别（分段控件 公 / 母）、生日 / 出生日期（日期选择器）、到家日期（日期选择器）
- 分区「健康信息」：当前体重（数值输入加单位 kg）、绝育情况（分段控件 已绝育 / 未绝育 / 不清楚）
- 分区「备注」：多行文本输入
- 底部固定主按钮「保存」
- 状态：正常填写；校验错误（某项未填写，显示红色描边和「此项为必填」提示）

PAGE-004 宠物档案首页
- 顶部区域：大号宠物头像、名字、「物种 · 品种 · 年龄」，右侧宠物切换器入口
- 分区「健康摘要」卡片式展示：当前体重；最近一次病例（就医日期加原因）；当前用药（同时显示来自「病例」和「生活记录」的用药，并用来源标签区分）；最近一次完成的提醒（类型加完成日期）；即将到期的提醒（类型加日期）；已逾期的提醒（使用错误色高亮，显示逾期天数）
- 分区「快捷操作」横向图标按钮：添加生活记录、新建病例、添加提醒、查看时间轴、查看相册
- 分区「近期记录」：该宠物最近 3 条时间轴内容预览
- 状态：正常（健康摘要信息完整）；部分空状态（没有病例或没有提醒时对应卡片显示「暂无记录」和添加入口）；逾期提醒状态（逾期项用错误色并排在摘要靠前位置）

PAGE-005 宠物专属时间轴
- 顶部导航栏：左侧返回，标题为宠物名字，右侧宠物切换器
- 内容类型筛选行：全部、生活记录、病例、相册、已完成提醒
- 时间轴列表按日期分组，条目格式与全部宠物时间轴一致，但弱化宠物头像
- 不提供新增内容入口
- 状态：正常（至少 5 条不同类型内容）；空状态（「这只宠物还没有记录」+「去添加生活记录」）

PAGE-006 添加生活记录（类型选择）
- 顶部导航栏：左侧「取消」，标题「添加生活记录」
- 类型选项列表（图标加名称加右侧箭头），分为两组：第一组 日记、体重变化、生日 / 到家日；第二组 绝育 / 发情、就医事件、自行用药、自定义事件
- 每个选项行高 48px 以上，图标风格统一

PAGE-007 生活记录编辑页
- 顶部导航栏：左侧「取消」，标题为记录类型名称，右侧「保存」
- 通用字段：日期（默认当前日期，可修改）
- 类型专属字段：
  · 日记：文字多行输入（必填）、图片 / 视频上传区（可为空，提示「可以先保存，之后再补充图片或视频」）
  · 体重变化：体重数值输入加单位
  · 生日 / 到家日：事件名称、日期
  · 绝育 / 发情：事件类型、日期
  · 就医事件：就医原因、日期、关联病例（可选「选择已有病例」「新建病例」「暂不关联」）
  · 自行用药：药品名称、日期、剂量、频次、备注
  · 自定义事件：标题、日期、描述
- 底部保存按钮
- 状态：日记类型且没有上传媒体（只显示文字输入，上传区为空占位）；必填未填写（错误提示）；已填写完整

PAGE-008 病例列表
- 顶部导航栏：标题「病例」，右侧「新建」按钮
- 病例卡片列表：就医日期（突出显示）、就医原因（主要内容）、诊断摘要（一行截断）、处理方式胶囊标签、附件缩略图（如有）
- 卡片按就医日期倒序排列
- 状态：正常（2 到 3 条病例）；空状态（「还没有病例记录」+「新建病例」）；信息待补充（卡片显示灰色「待补充」标记）

PAGE-009 病例详情
- 顶部导航栏：左侧返回，标题「病例详情」，右侧「编辑」
- 头部信息卡：就医日期、就医原因
- 分区字段列表：诊断信息、处理方式、用药信息、医疗备注、图片 / 附件（九宫格缩略图）
- 分区「关联内容」：关联的就医事件或生活记录
- 状态：完整（所有字段都有内容）；部分信息（未填写字段显示灰色「待补充」，可点击进入编辑）

PAGE-010 添加 / 编辑病例
- 顶部导航栏：左侧「取消」，标题「新建病例」，右侧「保存」
- 表单顶部提示文案：「可以先保存，之后再补充信息」
- 必填字段：就医日期（日期选择器）、就医原因（单行输入）
- 可选字段，带「选填」或「可稍后补充」提示：诊断信息（多行）、处理方式（多行）、用药信息（多行）、医疗备注（多行）、图片 / 附件上传
- 底部固定主按钮「保存」
- 状态：部分填写（仅填写必填项，其余为空）；校验错误（必填项缺失，红色提示）

PAGE-011 提醒列表
- 顶部导航栏：标题「提醒」，右侧「添加」按钮
- 分段控件：待处理 / 已完成 / 已逾期
- 待处理条目：提醒类型、下次提醒日期、周期说明、右侧「完成」按钮
- 已完成条目：提醒类型、完成日期、备注摘要
- 已逾期条目：提醒类型、逾期天数、错误色高亮、「完成」「编辑」「删除」操作
- 通知权限关闭时，页面顶部显示一条提示条
- 弹窗「标记完成」：显示完成日期（默认当前日期）、一个备注输入框，只有「取消」和「完成」，不提供图片上传
- 状态：待处理（至少 3 条）；已逾期（至少 2 条，突出逾期天数）；已完成（至少 2 条）；通知权限关闭（顶部提示条文案「通知权限已关闭，你仍可以在待处理列表查看提醒」）

PAGE-012 添加 / 编辑提醒
- 顶部导航栏：左侧「取消」，标题「添加提醒」，右侧「保存」
- 分区「提醒类型」：网格选择，示例选项 疫苗、驱虫、体检、喂药、洗澡、剪指甲、自定义事项
- 分区「周期建议」：显示系统给出的建议周期，说明「基于物种和提醒类型生成」；提示文案「建议周期仅供参考，请按实际情况或兽医建议修改」；周期输入 数值加单位（天 / 周 / 月）
- 分区「下一次提醒」：日期选择器
- 底部固定主按钮「保存」
- 状态：有默认周期（显示建议周期并允许修改）；无默认周期（周期输入为空，提示「请自定义提醒周期」）

PAGE-013 相册
- 顶部导航栏：左侧返回，标题「相册」，右侧「上传」按钮
- 媒体网格：3 列缩略图，视频显示居中播放图标
- 每条媒体显示来源标签：来自日记 / 来自其他生活记录 / 来自病例 / 独立上传
- 点击缩略图进入媒体详情
- 状态：正常（9 个以上缩略图，包含照片和视频）；空状态（「还没有照片和视频」+「上传照片或视频」）

PAGE-014 内容详情
- 顶部导航栏：左侧返回，右侧「编辑」和「删除」
- 内容头部：宠物头像和名字、内容类型胶囊标签、日期
- 内容主体随类型变化：生活记录 / 日记（媒体轮播、文字内容、事件字段）；病例（就医信息、诊断、处理方式、用药、附件，并显示「查看病例」入口）；已完成提醒（提醒类型、完成日期、备注）
- 删除操作需要二次确认弹窗
- 状态：有媒体（展示图片或视频）；无媒体（只展示文字）；删除确认弹窗

【全局状态补充】
除各页面自带状态外，再补充以下通用状态：
- 一组空状态界面，风格与主界面一致，每个空状态包含居中线性插画、一句说明文案、一个主操作按钮
- 两条应用内提示条：通知权限关闭（「通知权限已关闭，你仍可以在待处理列表查看提醒」加右侧「去开启」文字按钮）；提醒逾期（错误色底色或左侧错误色竖条，文案「有 2 项提醒已逾期」加右侧「查看」按钮）

【输出要求】
- 每个页面标注编号，格式为「PAGE-0xx 页面名 - 状态名」
- 14 个页面全部输出，不要遗漏，不要合并页面
- 所有页面复用同一套组件和视觉语言，保持整体一致
- 使用真实中文文案
- 只需要设计稿，不需要生成代码
```

## 3. 页面提示词

### PAGE-001 宠物列表

```text
请设计「宠物列表」页面。

页面目标：展示用户管理的全部宠物，支持进入某只宠物或添加新宠物。

布局（从上到下）：
1. 顶部导航栏：左侧返回，标题「我的宠物」，右侧「添加」文字按钮
2. 宠物卡片列表，每张卡片包含：
   - 左侧圆形宠物头像
   - 名字（分区标题样式）
   - 第二行：物种 · 品种
   - 第三行：性别 · 出生日期或年龄
   - 第四行：当前体重 · 绝育状态
   - 右侧进入箭头
3. 列表底部或导航栏右侧提供「添加宠物」主按钮

状态要求：
- 正常状态：展示 2 到 3 只宠物卡片
- 空状态：居中显示宠物插画，文案「还没有宠物，先添加一只吧」，下方主按钮「添加宠物」
```

### PAGE-002 全部宠物时间轴（App 默认入口）

## 5. 视觉设计规范

### 设计标准

- 间距优先使用 8px 体系
- 普通文字与背景对比度不低于 WCAG 2.2 AA 的 4.5:1
- 大字号文字与背景对比度不低于 3:1
- 非文字组件与相邻颜色对比度不低于 3:1
- 键盘 / 点击聚焦元素必须有清晰焦点状态
- 触控操作目标不小于 44 × 44px

### 布局规范

| 设计基准 | 375 × 812 pt |
