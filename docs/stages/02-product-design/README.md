# 阶段 2：产品设计与 UI/UX

## 目标
在开始开发前，明确做成什么样，以及用户如何使用它。

## 人的工作
- 确认页面主流程与关键功能
- 设计或调整 UI/UX 草图
- 审核 AI 生成的页面结构与交互说明
- 确认先做什么、后做什么

## AI 可以协助的内容
- 生成页面结构草案
- 生成交互流程说明
- 确认界面命名和组件逻辑
- 生成页面状态说明

## 必须产出的内容
- 产品设计说明
- 页面结构与功能流程
- UI/UX 草图或界面说明
- 关键交互行为
- 页面状态与异常状态说明

## 检查清单
- 页面目标是否清楚
- 用户主流程是否完整
- 关键操作是否明确
- 空状态、错误状态是否已说明
- 主要交互是否符合目标用户习惯
