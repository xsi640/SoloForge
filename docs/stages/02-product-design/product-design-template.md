# 阶段 2 产品设计模板入口

阶段 2 分为两个独立步骤，不能跳过 UX 直接生成 UI：

```text
阶段 2A：UX 设计
→ ux-design.md

阶段 2B：UI 设计
→ ui-design.md
```

## 阶段 2A：UX 模板

- [UX 设计模板](ux-design-template.md)
- 最终文档：`docs/stages/02-product-design/ux-design.md`

UX 阶段关注用户目标、用户流程、页面职责、交互行为和页面状态，不关注颜色、字体或视觉效果。

## 阶段 2B：UI 模板

- [UI 设计模板](ui-design-template.md)
- 最终文档：`docs/stages/02-product-design/ui-design.md`

UI 阶段只基于已确认的 UX 文档生成视觉设计提示词、界面效果图和设计规范，不重新改变用户流程或业务目标。

## 阶段 2 的固定交付物

1. `ux-design.md`：已确认的 UX 设计文档
2. `ui-design.md`：已确认的 UI 设计文档
3. UI 生成提示词和版本记录
4. pen.dev/stitch 生成的效果图、链接或导出文件
