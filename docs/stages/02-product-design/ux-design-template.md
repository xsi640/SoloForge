## 8. UX 验收标准

- [ ] 用户目标明确
- [ ] 主流程可以完整走通
- [ ] 页面职责没有重复或遗漏
- [ ] 主要操作和次要操作已经区分
- [ ] 分支流程已经说明
- [ ] 加载、空、错误、成功状态已经说明
- [ ] 中断、返回和恢复路径已经说明
- [ ] 用户反馈足够明确
- [ ] 没有在 UX 阶段提前决定视觉样式
- [ ] 已完成人工确认
