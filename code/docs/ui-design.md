## 2. 设计图提示词

### 2.1 完整提示词（一次性生成全部页面）

```text
请设计一套桌面 Web 应用的高保真 UI 设计图，应用是一个面向 10 人小团队的任务看板工具，共 5 个页面，请逐页生成，不要合并页面，不要遗漏。

【整体风格】
现代简洁的企业内部工具风格。深色顶栏 + 浅灰页面背景 + 白色卡片，信息密度适中，边框轻量，不使用渐变、玻璃拟态或夸张阴影，强调清晰层级和可读性。

【设计基准与布局】
- 画布宽度 1440px，最小可用宽度 1280px，仅桌面端。
- 顶部栏固定高度 56px，横向铺满。
- 主内容区左右留白 24px。
- 看板为三列等宽并排布局，列间距 16px，列内卡片纵向排列、间距 12px。
- 弹层居中，`PAGE-004` 宽 480px，`PAGE-005` 宽 560px。
- `PAGE-003` 内容最大宽度 960px 居中。

【色彩】
- 主色 #2563EB（主按钮、选中态、拖拽放置指示），悬停 #1D4ED8。
- 顶栏背景 #1E293B，顶栏文字 #F8FAFC。
- 页面背景 #F1F5F9，卡片/表格/弹层背景 #FFFFFF。
- 边框与分隔线 #E2E8F0。
- 正文文字 #0F172A，次要文字 #64748B。
- 优先级：高 #DC2626、中 #EA580C、低 #64748B。
- 截止日期：超期 #DC2626、临期 #EA580C。
- 成功 #16A34A，错误 #DC2626，警告底色 #FEF3C7。
- 禁用背景 #CBD5E1，禁用文字 #94A3B8。

【字体】
无衬线系统字体栈（Inter / PingFang SC / Microsoft YaHei 回退）。
- 页面标题 20px/600，列标题 15px/600，卡片标题 14px/500。
- 正文与表单 14px/400，辅助信息与标签 12px/400，按钮 14px/500。

【组件规范】
- 顶部栏：左侧应用名，中间搜索框，右侧依次为筛选入口、提醒铃铛（可带数量角标）、当前用户名（含退出）、成员管理入口（仅管理员可见）。
- 看板列：列标题 + 任务计数 + 卡片区 + 底部「+ 添加任务」。
- 任务卡片：第一行为标题，第二行为负责人、截止日期、优先级标签。拖拽时卡片轻微抬起、阴影加深。
- 按钮：主按钮实心主色，次按钮白底描边，危险按钮红色。
- 输入框与下拉：白底描边，聚焦时主色描边。
- 优先级标签：小圆角胶囊，按优先级取色并显示文字（高/中/低）。
- 提醒面板：铃铛展开的临期与超期任务清单，条目可点击，带文字标识。
- 弹层：标题 + 内容区 + 底部按钮（取消 / 确认）。
- 成员管理表格：登录名、显示名、状态标签、操作按钮。
- 全局提示：成功绿、错误红，按钮操作中显示加载态。

【可用性要求】
- 所有可交互元素都要有悬停态和聚焦态。
- 正文与背景对比度满足 WCAG AA。
- 状态不得仅靠颜色区分：临期与超期同时显示文字标识，优先级标签带文字。
- 空状态、加载态、错误态在三列区域内占用明确占位。
- 表单必填项有标识，校验失败时字段级提示。

【逐页要求】

PAGE-001 登录页
页面目标：完成身份认证。
布局：页面垂直水平居中一张登录卡片，卡片宽 400px，白底、圆角 8px、轻边框；卡片内自上而下为应用名、登录名输入框、密码输入框、登录按钮（主按钮，宽满）。
状态：
- 默认：空表单，登录按钮可点击。
- 输入中：已填入部分内容。
- 提交中：按钮显示加载态并禁止重复点击。
- 登录失败：表单上方显示红色错误提示「账号或密码错误」，保留已输入内容。

PAGE-002 看板页
页面目标：展示三列看板与任务卡片，承载搜索、筛选、提醒与弹层唤起。
布局：顶部 56px 深色顶栏；下方为主内容区，先一行筛选条（含「查看全部」切换、筛选条件、结果提示），再是三列等宽看板：待办、进行中、完成。
列结构：每列有列标题与任务计数，卡片纵向排列，列底部固定「+ 添加任务」。
卡片内容：标题、负责人、截止日期、优先级标签；超期日期标红并带「已超期」文字，临期标橙并带「临期」文字。
状态：
- 加载中：三列区域内显示骨架占位。
- 加载失败：显示失败提示与「重试」按钮。
- 看板无任务：全局空状态，引导创建第一个任务。
- 我的任务为空：默认筛选下无结果，引导查看全部任务或创建任务。
- 筛选无结果：显示无匹配结果，引导清除筛选条件。
- 正常：三列展示任务卡片。
- 拖拽中：被拖卡片抬起，目标列显示放置指示区域。
- 提醒有未处理项：铃铛显示数量角标。
- 提醒无未处理项：铃铛无角标。

PAGE-003 成员管理页
页面目标：仅管理员可见，维护成员账号、密码与启停状态。
布局：保留顶部栏；内容区最大宽度 960px 居中；标题行右侧放「新增成员」主按钮；下方为成员表格，列为登录名、显示名、状态标签、操作按钮（重置密码、停用/启用）。
状态：
- 正常：成员列表展示。
- 新增表单展开：在表格上方展开一行表单，含登录名、显示名、密码、状态，以及保存与取消。
- 重置密码弹窗：弹层内含新密码输入框，底部为取消与确认。
- 停用或启用确认：二次确认弹层，明确提示停用后该成员无法登录、其任务保留。

PAGE-004 新建任务弹层
页面目标：收集新任务字段并提交创建。
布局：居中弹层，宽 480px，顶部标题「新建任务」，内容区自上而下为标题（必填）、负责人下拉、状态下拉、截止日期、优先级下拉（默认中）、描述多行文本，底部为取消与保存。
状态：
- 默认：空表单，状态预置为用户点击的那一列。
- 校验失败：标题为空时字段下方显示红色提示，不清空其他输入。
- 提交中：保存按钮显示加载态，禁止重复提交。

PAGE-005 任务详情弹层
页面目标：展示任务全部字段，支持编辑、改状态与删除。
布局：居中弹层，宽 560px，顶部标题「任务详情」，内容区为可编辑字段：标题、负责人、状态、截止日期、优先级、描述；底部左侧为删除按钮（危险样式），右侧为取消与保存。
状态：
- 默认：展示任务全部字段值。
- 编辑中：字段可修改。
- 删除确认：二次确认弹层，提示删除后不可恢复。
- 保存中：保存按钮显示加载态。

【全局补充状态】
- 会话过期：跳转或引导回登录页，并给出提示。
- 操作失败：任意写操作失败时显示「操作失败，请重试」，并保留用户输入。
- 操作成功：创建任务、保存任务、拖拽改状态、删除任务、成员新增与密码重置完成后显示成功提示。

【输出要求】
- 按 PAGE-001 到 PAGE-005 顺序编号输出，每页标注页面名称。
- 每个页面都要包含上述列出的状态样式，状态可用并排或分组的方式呈现。
- 不要改变页面数量，不要合并页面，不要新增页面。
- 最终交付物是设计图；如果必须先生成 HTML/CSS 才能渲染出图，这部分只作为出图手段，不作为交付的生产代码。
```

## 5. 视觉设计规范

### 设计标准

- 桌面 Web 优先，基准画布 1440px，最小可用宽度 1280px，不做移动端适配。
- 仅浅色主题，不做深色模式切换。
- 圆角统一 6-8px，边框统一 1px `#E2E8F0`，不使用渐变、玻璃拟态与重阴影；阴影仅用于弹层与拖拽中的卡片。

### 布局

- 顶部栏固定高 56px，横向铺满；内容区左右留白 24px。
- 看板三列等宽并排，列间距 16px；列内卡片纵向排列，间距 12px。
- `PAGE-003` 内容最大宽度 960px 居中。

## 8. UI 验收标准

- 5 个页面全部产出设计图，编号与 `ux-design.md` 中的 `PAGE-001` ~ `PAGE-005` 一一对应，无合并、无遗漏、无新增页面。
- 设计图使用本文档定义的色彩、字体与组件规范，不同页面之间同一组件样式一致。
- 看板三列等宽并排，卡片正面仅含标题、负责人、截止日期与优先级标签，描述不出现在卡片正面。
- 临期与超期不仅使用颜色，还带「临期」「已超期」文字标识；优先级标签带文字。
- 三种空状态（`STATE-007`、`STATE-008`、`STATE-009`）在视觉上可区分。
- 加载、失败、空、正常、拖拽状态均有对应画面。
- `PAGE-004` 与 `PAGE-005` 以弹层形式出现在看板上下文之上，遮罩下仍可见看板。
- 成员管理页无删除成员入口、无自助注册入口；登录页无注册与忘记密码入口。
- 未出现需求与 UX 阶段已排除的内容：评论、附件、子任务、标签、甘特图、报表、归档、多项目切换、权限分级、外部提醒通道、自定义状态列、HTTPS 入口、移动端布局。
