# UX 设计：团队任务看板应用

本文件是阶段 2B 生成 UI 文档与设计图的唯一 UX 输入。UX-001 为本次 UX 设计的任务编号。

## 1. UX 设计目标

- 让 10 人左右的小团队在不依赖口头同步的前提下，一眼看到「谁在做什么、进行到哪一步」。
- 让任务记录和状态更新足够轻，拖一下就完成状态流转，避免因为操作繁琐而不愿意维护看板。
- 让「我该做什么」在登录后立即可见，减少在整块看板中自行寻找自己任务的成本。
- 让快到期的任务被主动推到用户面前，而不是靠人记住日期。
- 让管理员能在应用内完成账号的开通与维护，不需要碰服务器。

## 2. 用户角色和使用场景

### USER-001 普通成员

- 能访问的页面：`PAGE-001`、`PAGE-002`、`PAGE-004`、`PAGE-005`。
- 使用场景：每天登录后查看自己的任务，拖动卡片更新状态，创建新任务，临时按条件查找任务，处理临期与超期提醒，退出登录。
- 前提条件：已由管理员创建账号并处于启用状态，处于内网环境，可访问服务器 IP。

### USER-002 管理员

- 能访问的页面：`USER-001` 的全部页面，外加 `PAGE-003`。
- 使用场景：在成员入职时新增账号，成员忘记密码时重置密码，成员离岗时停用账号；日常使用与 `USER-001` 完全一致。
- 权限说明：管理员在任务、看板、拖拽、编辑、删除等操作上与普通成员完全一致，不存在任务层面的权限分级；管理员身份的意义仅在于可见成员管理入口。

## 3. 用户主流程

### FLOW-001 登录并进入看板

| 步骤 | 用户做什么 | 系统反馈 |
|---|---|---|
| FLOW-001-01 | 打开应用地址（内网 IP） | 未登录时进入 `PAGE-001`，展示登录名与密码输入框 |
| FLOW-001-02 | 输入登录名与密码，点击登录 | 按钮进入提交中状态 |
| FLOW-001-03 | 等待校验 | 校验通过后进入 `PAGE-002`，看板默认按「负责人 = 我」筛选 |
| FLOW-001-04 | 查看自己的任务 | 三列展示我名下的任务卡片，顶部显示提醒入口 |

### FLOW-002 创建任务

| 步骤 | 用户做什么 | 系统反馈 |
|---|---|---|
| FLOW-002-01 | 在目标列底部点击「+ 添加任务」 | 打开 `PAGE-004` 新建表单，状态默认取该列 |
| FLOW-002-02 | 填写标题（必填）、负责人、截止日期、优先级、描述 | 表单字段可见，标题为空时提交被阻止并提示 |
| FLOW-002-03 | 点击保存 | 表单进入提交中状态 |
| FLOW-002-04 | 等待保存 | 表单关闭，新卡片出现在目标列顶部并短暂高亮 |

### FLOW-003 更新任务状态

| 步骤 | 用户做什么 | 系统反馈 |
|---|---|---|
| FLOW-003-01 | 按住卡片拖到另一列 | 目标列出现放置提示 |
| FLOW-003-02 | 松开卡片 | 卡片落到目标列并短暂高亮，状态已更新 |
| FLOW-003-03 | 或在 `PAGE-005` 详情弹窗中修改状态下拉 | 保存后卡片移动到对应列 |

### FLOW-004 查看与编辑任务详情

| 步骤 | 用户做什么 | 系统反馈 |
|---|---|---|
| FLOW-004-01 | 点击任意卡片 | 打开 `PAGE-005` 详情弹窗，展示全部字段 |
| FLOW-004-02 | 修改字段并保存 | 弹窗内字段可编辑，保存后卡片同步更新 |
| FLOW-004-03 | 或点击删除 | 弹出二次确认，确认后卡片从看板移除 |

### FLOW-005 搜索与筛选任务

| 步骤 | 用户做什么 | 系统反馈 |
|---|---|---|
| FLOW-005-01 | 在搜索框输入关键词 | 看板按标题与描述匹配，实时刷新结果 |
| FLOW-005-02 | 选择负责人、优先级或截止日期条件 | 看板按组合条件刷新结果 |
| FLOW-005-03 | 点击「查看全部」 | 清除「负责人 = 我」的默认筛选，展示全部任务 |
| FLOW-005-04 | 清除筛选条件 | 恢复默认筛选状态 |

### FLOW-006 接收并处理提醒

| 步骤 | 用户做什么 | 系统反馈 |
|---|---|---|
| FLOW-006-01 | 登录后停留或使用看板 | 系统在登录时拉取一次，之后每 5 分钟刷新一次提醒数据 |
| FLOW-006-02 | 查看顶部铃铛 | 铃铛显示我名下临期与超期任务的数量角标 |
| FLOW-006-03 | 点击铃铛 | 展开我名下临期与超期任务清单 |
| FLOW-006-04 | 点击清单中的某条任务 | 打开 `PAGE-005` 详情弹窗处理该任务 |

### FLOW-007 管理员管理成员

| 步骤 | 用户做什么 | 系统反馈 |
|---|---|---|
| FLOW-007-01 | 在 `PAGE-002` 顶部右上角点击「成员管理」 | 进入 `PAGE-003`，展示成员列表 |
| FLOW-007-02 | 点击「新增成员」 | 展开新增表单，填写登录名、显示名、密码、状态 |
| FLOW-007-03 | 保存新成员 | 新成员出现在列表中且状态为启用 |
| FLOW-007-04 | 对某成员点击「重置密码」 | 弹出输入新密码的弹窗，保存后立即生效 |
| FLOW-007-05 | 对某成员点击「停用」或「启用」 | 需二次确认，确认后成员状态切换 |

## 4. 分支流程

- `BRANCH-001` 默认筛选与全量视图切换：登录后默认「负责人 = 我」；点击「查看全部」切换为全量三列看板；再次点击恢复默认。该切换属于 `PAGE-002` 的筛选能力，不构成独立页面。
- `BRANCH-002` 通过拖拽更新状态：拖拽是主要方式，拖拽目标列可为任意一列（含回退到原列，此情况视为无变化）。
- `BRANCH-003` 通过详情弹窗更新状态：在 `PAGE-005` 内使用状态下拉完成同样的状态更新，作为拖拽的替代路径，适用于误拖或不便拖拽的情况。两条路径必须产生一致的结果。
- `BRANCH-004` 删除任务：在 `PAGE-005` 中触发删除，必须先经过二次确认；取消则不做任何变更。
- `BRANCH-005` 新增成员：登录名重复时不允许保存并提示。
- `BRANCH-006` 重置密码：管理员输入新密码并保存后立即生效，该成员下次登录使用新密码，不强制其修改。
- `BRANCH-007` 停用与启用成员：停用后该成员无法登录，其名下任务保留、负责人不变；启用后恢复登录能力。停用与启用均需二次确认。
- `BRANCH-008` 提醒范围：提醒仅覆盖当前登录用户名下的任务；他人的临期与超期任务通过看板卡片上的日期标红体现，不进入铃铛清单。

## 5. 异常、中断和返回路径

- `ERROR-001` 登录失败：提示「账号或密码错误」，不区分是账号不存在还是密码错误；不清空已输入的登录名；不做连续输错锁定。
- `ERROR-002` 未登录或会话过期：访问看板页时被引导回 `PAGE-001` 重新登录；关闭浏览器后再次打开需要重新登录，不提供「记住我」。
- `ERROR-003` 看板或成员列表加载失败：展示加载失败提示与「重试」操作，重试后仍失败保持提示。
- `ERROR-004` 操作失败（保存任务、更新状态、删除任务、成员操作）：提示「操作失败，请重试」，并保留用户已输入的内容或未确认的表单状态，避免数据丢失。
- `ERROR-005` 拖拽失败：卡片回到原列，状态保持原值，并提示操作失败。
- `ERROR-006` 新增成员时登录名重复：提示登录名已存在，保留其余已填写内容，允许修改后重新提交。
- `ERROR-007` 管理员停用自己：提示不可停用当前登录账号，并阻止该操作。
- `ERROR-008` 表单校验中断：标题为空或必填项缺失时阻止提交，并在对应字段处提示，不清空已填内容。
- `ERROR-009` 中断与返回：`PAGE-004` 与 `PAGE-005` 均可在未保存时关闭，关闭后不产生任何数据变更；已输入但未保存的内容不保留。

## 6. 页面职责

| 页面 | 名称 | 职责 | 入口 | 出口 |
|---|---|---|---|---|
| `PAGE-001` | 登录页 | 完成身份认证，引导未登录用户进入应用 | 直接访问应用地址 | 登录成功后进入 `PAGE-002` |
| `PAGE-002` | 看板页 | 展示三列看板与任务卡片，承载筛选、搜索、提醒、以及新建与详情弹层的唤起 | 登录成功后；从 `PAGE-003` 返回 | 退出登录回 `PAGE-001`；管理员可进入 `PAGE-003` |
| `PAGE-003` | 成员管理页 | 仅管理员可见，维护成员的账号、密码与启停状态 | `PAGE-002` 顶部「成员管理」入口 | 返回 `PAGE-002` |
| `PAGE-004` | 新建任务弹层 | 收集新任务字段并提交创建 | `PAGE-002` 各列底部「+ 添加任务」 | 保存成功或取消后回到 `PAGE-002` |
| `PAGE-005` | 任务详情弹层 | 展示任务全部字段，支持编辑字段、修改状态与删除任务 | `PAGE-002` 点击卡片；提醒清单点击条目 | 保存或关闭后回到 `PAGE-002` |

页面职责边界规则：

- 看板整体展示、搜索、筛选、提醒入口、弹层唤起全部归 `PAGE-002`，`PAGE-002` 保持单页不拆分。
- 任务字段的创建归 `PAGE-004`，任务字段的查看、编辑与删除归 `PAGE-005`，两者不得重复实现对方的表单职责；`PAGE-004` 只负责创建，`PAGE-005` 只负责已存在任务。
- 状态列的展示与拖拽交互归 `PAGE-002`，状态值的写入统一由任务更新逻辑完成。
- 账号相关的一切归 `PAGE-001` 与 `PAGE-003`，`PAGE-002` 不承担账号维护职责，仅提供入口与退出。
- 提醒的清单与其条目跳转归 `PAGE-002`，提醒的具体呈现依赖截止日期字段，字段本身归 `PAGE-005`。

## 7. 页面关系

```text
PAGE-001 登录页
   │ 登录成功
   ▼
PAGE-002 看板页 ──「+ 添加任务」──▶ PAGE-004 新建任务弹层
   │   ▲                                │ 保存/取消
   │   └────────────────────────────────┘
   │
   ├── 点击卡片 / 提醒条目 ──▶ PAGE-005 任务详情弹层
   │   ▲                          │ 保存/关闭
   │   └──────────────────────────┘
   │
   └── 成员管理（仅 USER-002）──▶ PAGE-003 成员管理页 ──返回──▶ PAGE-002
退出登录：PAGE-002 ──▶ PAGE-001
```

- `PAGE-004` 与 `PAGE-005` 是 `PAGE-002` 上的弹层，不脱离看板上下文；关闭后用户停留位置不变。
- `PAGE-003` 是独立页面，返回后回到进入前的 `PAGE-002` 状态（保留当前筛选条件）。

## 8. 关键交互

- `INTERACTION-001` 登录提交：点击登录按钮或按回车提交；提交中按钮不可重复点击。
- `INTERACTION-002` 列内添加任务：每列底部固定「+ 添加任务」，点击唤起 `PAGE-004`，状态预置为该列。
- `INTERACTION-003` 卡片点击：点击卡片任意位置打开 `PAGE-005`，卡片进入选中状态。
- `INTERACTION-004` 拖拽换列：按住卡片拖动到目标列并松开完成状态更新；拖拽中目标列给出放置反馈。
- `INTERACTION-005` 详情内改状态：`PAGE-005` 内状态下拉可切换三列状态，保存后卡片移动。
- `INTERACTION-006` 编辑保存：`PAGE-005` 内修改字段后保存，字段即时更新到卡片。
- `INTERACTION-007` 删除确认：点击删除弹出二次确认，确认执行、取消放弃。
- `INTERACTION-008` 搜索输入：输入关键词即时过滤，匹配标题与描述。
- `INTERACTION-009` 筛选选择：负责人、优先级、截止日期三类条件可组合；「已超期」作为截止日期的快捷条件。
- `INTERACTION-010` 查看全部切换：一键在全量视图与「负责人 = 我」之间切换，入口显眼且当前状态可辨识。
- `INTERACTION-011` 提醒入口：顶部铃铛显示角标数量，点击展开清单，点击清单条目打开 `PAGE-005`。
- `INTERACTION-012` 成员管理入口：仅 `USER-002` 在顶部右上角可见。
- `INTERACTION-013` 新增成员：填写登录名、显示名、密码、状态后保存。
- `INTERACTION-014` 重置密码：点击后弹出输入新密码弹窗，保存立即生效。
- `INTERACTION-015` 停用与启用：点击后二次确认，确认后切换状态；停用当前登录账号被阻止。
- `INTERACTION-016` 退出登录：位于顶部当前用户处，点击后回到 `PAGE-001`。
- `INTERACTION-017` 弹层关闭：`PAGE-004` 与 `PAGE-005` 支持关闭操作，未保存内容不保留。

## 10. 用户反馈

### 反馈规则

- 成功反馈：创建任务、保存任务、拖拽改状态、删除任务、成员新增与密码重置等操作完成后给出明确成功提示。
- 失败反馈：任何写操作失败统一提示「操作失败，请重试」，并保留用户输入。
- 进行中反馈：登录、保存、删除等操作期间按钮进入进行中状态，禁止重复提交。
- 卡片变化反馈：新建或移动的卡片短暂高亮，帮助用户确认变化位置。
- 空状态反馈：区分「看板无任务」「我的任务为空」「筛选无结果」三种情况，给出不同引导。

| 编号 | 场景 | 文案要点 |
|---|---|---|
| `CONTENT-001` | 登录失败 | 「账号或密码错误」，不透露具体原因 |
| `CONTENT-002` | 看板无任务 | 引导先创建第一个任务 |
| `CONTENT-003` | 我的任务为空 | 引导查看全部任务或创建任务 |
| `CONTENT-004` | 筛选无结果 | 引导清除筛选条件 |
| `CONTENT-005` | 加载失败 | 提示加载失败并提供重试 |
| `CONTENT-006` | 操作失败 | 「操作失败，请重试」 |
| `CONTENT-007` | 删除确认 | 明确提示删除后不可恢复 |
| `CONTENT-008` | 停用确认 | 明确提示停用后该成员无法登录，其任务保留 |
| `CONTENT-009` | 停用自己被阻止 | 提示不可停用当前登录账号 |

## 11. UX 验收标准

- `USER-001` 能在登录后 1 次操作内看到属于自己的任务，并能切换回全部任务视图。
- 创建任务的完整路径不超过「点击添加 → 填表 → 保存」三步，且新建卡片出现在所选列。
- 状态更新既可拖拽完成，也可在详情弹窗内完成，且两种方式结果一致。
- 任务详情可编辑全部 6 个字段（标题、负责人、状态、截止日期、优先级、描述）并支持删除。
- 搜索与筛选（关键词、负责人、优先级、截止日期含已超期）能组合使用并准确命中任务。
- 铃铛角标只统计当前用户名下的临期与超期任务，点击条目可直接打开对应任务详情。
- `USER-002` 能完成新增成员、重置密码、停用与启用，且无法停用自己；`USER-001` 看不到成员管理入口。
- 页面状态覆盖默认、加载、空、成功、错误五类，且三种空状态可区分。
